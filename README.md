# Kestra Fantasy Football Draft Analysis
This repository contains examples of Kestra Flows that will pull down live data from your fantasty football application of choice and suggest a draft pick

## Installation

Dependencies are managed via `requirements.txt` and can be installed using [uv](https://docs.astral.sh/uv/):

```bash
uv pip install -r requirements.txt
```

If you don't have `uv` installed yet, see the [installation guide](https://docs.astral.sh/uv/getting-started/installation/).
